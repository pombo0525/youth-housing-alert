# 놓침방지 청년주거 알리미

관심 지역과 주택 종류를 고르면, 진행 중인 청년·공공 임대주택 공고와 접수 기간을 한 화면에 보여주는 사이트예요.

- 공고 정보는 공공데이터포털(한국토지주택공사 분양임대공고문 조회 서비스, 국토교통부 마이홈포털 공공주택 모집공고 조회 서비스)에서 하루 4번 자동으로 받아와요.
- 신청 전에는 꼭 공고문 원문을 확인하세요.

## 파일 안내

| 파일 | 하는 일 |
|---|---|
| `index.html` | 사이트 화면 |
| `data/notices.json` | 자동으로 받아온 공고 목록 (직접 고치지 않아도 돼요) |
| `scripts/fetch_notices.py` | 공고를 받아오는 프로그램 |
| `.github/workflows/update.yml` | 하루 4번 자동 실행 설정 |
| `youth-housing-intro.mp4` | 소개 영상 |

## 인증키

인증키는 저장소 **Settings → Secrets and variables → Actions** 의 `DATA_GO_KR_KEY` 에만 넣어요. 파일 안에 직접 적지 마세요.
