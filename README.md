# 서울·경기 청년임대주택 알리미

서울·경기에 사는 청년이 **청년임대주택 모집 공고를 놓치지 않도록** 돕는 사이트예요.
나라의 지원으로 보증금과 월세를 저렴하게 낼 수 있는 집의 모집 공고를 다섯 곳에서 모아, 접수 마감이 가까운 순서로 한 화면에 보여줘요.

사이트 주소: https://pombo0525.github.io/youth-housing-alert/

## 이렇게 써요

1. **조건 고르기:** 지역(서울·경기)과 관심 있는 주택 종류(행복주택, 매입임대-청년, 전세임대-청년, 청년안심주택 등)를 골라요. 고른 조건은 다음에 열 때도 기억해요.
2. **공고 보기:** 조건에 맞는 공고가 마감이 가까운 순서로 나와요. 앞으로 2주 동안의 접수 기간을 달력으로 한눈에 볼 수 있고, 공고마다 어느 기관의 공고인지 표시돼요.
3. **공고문 확인·달력 저장:** 버튼을 누르면 해당 기관 사이트의 공고문으로 바로 이동해요. 접수 시작일과 마감일을 휴대폰이나 PC 달력에 저장할 수도 있어요.

## 공고를 모아오는 곳

GitHub Actions가 하루 4번(한국 시간 오전 6시, 낮 12시, 오후 6시, 자정쯤) 자동으로 공고를 새로 모아요.

| 출처 | 받아오는 방법 |
|---|---|
| LH 한국토지주택공사 | 공공데이터포털 공식 API (분양임대공고문 조회 서비스) |
| 마이홈포털 (국토교통부) | 공공데이터포털 공식 API (공공주택 모집공고 조회 서비스) |
| 서울시 청년안심주택 | 청년안심주택 홈페이지의 공개 공고 게시판 |
| SH 서울주택도시공사 | 서울주거포털의 SH 공공임대 공개 목록 |
| GH 경기주택도시공사 | GH 청약센터의 공개 임대 공고 목록 |

- 공식 API가 없는 세 곳은 robots.txt로 자동 수집 허용 여부를 확인한 공개 페이지만 읽어요.
- 서울·경기(또는 전국) 공고 중 청년이 지원할 수 있는 임대주택만 남기고, 신혼부부·고령자·분양 공고 등은 빼요.
- 한 곳에서 공고를 받아오지 못하면 그곳은 지난번에 받은 공고를 그대로 보여줘요.

## 알아 둘 점

- 공고가 올라온 뒤 사이트에 보이기까지 최대 6시간쯤 걸릴 수 있어요.
- SH 목록에는 접수 기간이 없어서 "모집중" 상태만 보여줘요.
- 청년안심주택 공고 중 접수 기간이 PDF에만 있는 경우에는 시작일만 보여주고 "마감일은 공고문 확인"이라고 안내해요.
- 신청 자격(나이·소득·무주택 등)과 정확한 일정은 신청 전에 꼭 공고문 원문으로 확인하세요.

## 파일 안내

| 파일 | 하는 일 |
|---|---|
| `index.html` | 사이트 화면 |
| `youth-housing-intro.mp4` | 사이트 사용법 소개 영상 (28초) |
| `data/notices.json` | 자동으로 모은 공고 목록 (직접 고치지 않아도 돼요) |
| `scripts/fetch_notices.py` | 다섯 곳에서 공고를 모아오는 프로그램 |
| `.github/workflows/update.yml` | 하루 4번 자동 실행 설정 |

## 인증키

공공데이터포털 인증키는 저장소 **Settings → Secrets and variables → Actions** 의 `DATA_GO_KR_KEY` 에만 넣어요. 파일 안에는 적지 않아요.
